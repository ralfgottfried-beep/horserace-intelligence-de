# HorseRace Intelligence DE v0.3

Start: Python 3 installieren, im entpackten Ordner `python server.py` ausführen und http://localhost:8765 öffnen.

Die App lädt ohne Login öffentliche Rennkalenderdaten von Deutscher Galopp. Für den Server ist Internetzugang nötig. Der Quellseiten-HTML-Aufbau kann sich ändern. Ein HTTP-Fehler, eine Blockierung oder geänderte Tabellenstruktur führen zu einer transparenten Leeranzeige statt Fantasiedaten. Keine garantierte Live-Verfügbarkeit.

Pferd/Jockey-Detaildaten sind in dieser Version noch nicht integriert; verifizierte Detaildatenadapter und Nutzungsrechte sind separat zu prüfen. Daten anderer Webseiten werden nicht ungeprüft kopiert. Die Quellseite bleibt verlinkt.
